# 반복 버그 — 실무 디버깅으로 전환

이 문제는 이미 여러 번 수정했는데 같은 증상 또는 다른 부작용이 반복되고 있다.
**추측해서 코드를 계속 수정하지 않는다.**

## 원칙

같은 문제를 2~3회 이상 수정했는데 해결되지 않았다면 **증상별 패치를 더 추가하지 않는다.**
지금까지의 변경과 증상을 근거로 **근본 원인을 다시 진단**한다.

## 1. 재현 조건을 정확히 정의

먼저 사용자에게 확인하거나, 이미 알고 있으면 명시적으로 적는다.

- Web / Mobile browser / PWA(standalone) 중 어디인지
- 기기와 브라우저 (iPhone Safari? 설치형 PWA? Chrome Android?)
- 화면 진입 → 동작 → 문제 발생까지의 **정확한 순서**
- 키보드 열림 여부, 스크롤 위치, focus된 요소, 내용 길이(짧음/김)

조건이 애매하면 여기서 멈추고 물어본다. 잘못된 재현 조건 위의 수정은 전부 낭비다.

## 2. 관련 코드만 추적

- 현재 증상에 **직접** 영향을 주는 DOM / CSS / JS / 상태만 확인
- **이미 실패한 수정 위에 또 보정값을 얹지 않는다**
- 이전 패치들이 서로 충돌하고 있는지 확인 — 반복 버그의 흔한 정체가 이것이다
- 같은 CSS 셀렉터가 여러 media block에 흩어져 있으면 전부 grep해서 최종 승자를 확인

## 3. 추측하지 말고 실제 값을 측정

viewport / keyboard / scroll 문제라면 아래 값을 **실제로 읽는다.**

```js
window.innerHeight
window.visualViewport.height
window.visualViewport.offsetTop
scroller.scrollTop / scrollHeight / clientHeight
document.activeElement
getComputedStyle(el).position   // sticky가 정말 sticky인지
el.getBoundingClientRect()
```

로컬에서 실기기 값을 볼 수 없으면 **최소한의 임시 debug panel / logging을 만들어도 된다.**
사용자가 아이폰에서 실행하고 결과나 스크린샷을 보낼 수 있게 만든다.

임시 debug panel은 원인을 찾은 뒤 **반드시 제거**한다.

## 4. 브라우저 자체 문제 가능성 확인

iOS / WebKit / PWA standalone 특유의 현상일 수 있다. 코드 문제라고 단정하기 전에
공식 문서와 알려진 브라우저 이슈를 확인한다. 웹페이지가 없앨 수 없는 것
(autofill 액세서리 바, 키보드 애니메이션 중 중간 resize 이벤트 등)을 코드로
이기려는 시도가 반복 패치의 원인인 경우가 많다.

## 5. 원인을 찾기 전까지 보정 패치를 누적하지 않는다

특히 이런 방식은 금지:

- 원인을 모른 채 `top` / `bottom` / `height` 숫자를 계속 바꾸기
- 새로운 매직넘버 추가
- 이유 없는 `setTimeout` / `requestAnimationFrame` 추가
- viewport 보정값을 여러 위치에서 중복 계산
- 버그 하나를 고치려고 전체 레이아웃 변경

## 6. 원인이 확인되면 가장 작은 수정으로 해결

동시에 **이번 원인 때문에 들어갔던 실패 패치와 불필요한 보정도 함께 걷어낸다.**
최종 코드에 임시 해결책이 누적되지 않게 한다.

## 7. 회귀 확인

이번 문제와 관련된 조합만 확인한다.

- Web / Mobile / PWA
- 키보드 열기 · 닫기
- 짧은 내용 · 긴 내용
- 스크롤 전 · 스크롤 후 · 스크롤 중간에서 탭

## 보고 기준

현재 환경에서 실제 iOS/PWA 동작을 재현할 수 없으면 "수정 완료" / "검증 완료"라고
추측해서 쓰지 않는다. 반드시 세 가지로 나눠서 보고한다.

1. **확인된 사실** — 코드/브라우저에서 실제로 본 것
2. **코드상 추론** — 근거는 있지만 실행으로 확인하지 못한 것
3. **실기기에서 확인해야 할 것** — 사용자가 아이폰에서 봐줘야 하는 것

목표는 이번 증상을 눈앞에서 없애는 것이 아니라, **왜 발생하는지를 찾아 재발하지
않도록** 고치는 것이다.
