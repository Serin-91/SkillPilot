# 규칙 — 편집기 / 메모지 / 캐럿 / ref

`src/components/memo/*` · `src/lib/memo/*` · 편집 화면 CSS를 만질 때 읽는다.
경위·실측은 `docs/incidents.md`.

## 캐럿 / 포커스

- 캐럿 노출을 "iOS보다 먼저" 하려고 디바운스를 풀지 마라 — 넣었다가 같은 날 되돌렸다.
- 캐럿 노출의 소유자는 정확히 하나다. 후보를 **내가 부른 API 안쪽까지** 세라.
- `pointerdown` preventDefault로는 포커스를 못 지킨다 — `mousedown`도 같이 막아라.
  편집창 안 버튼 전부에 걸려 있어야 한다.
- 편집 스크롤러에 `onScroll` + `setState`를 달지 마라(→ `ui-layout.md`).

## ref / 마운트

- **같은 ref를 여러 벌 마운트된 컴포넌트가 공유하면 "마지막 사본"이 이긴다.**
  `<dialog>`는 닫혀도 자식이 살아 있다 — 같은 노드가 여러 dialog에 중복 마운트됐는지 세라.
- 에디터 handle ref는 화면 수만큼 있다.
- 로컬이 **한 번도** 재현하지 못하는 버그는 타이밍 경합이다.
  경합을 **이기려 하지 말고 없애라.** 그리고 값이 아니라 **그 값의 소유자**를 봐라.

## 메모지 색 / 테마

- **메모지 색은 세 벌이다** — 하나를 칠하면 나머지 둘을 반드시 같이 세라.
- `.postit-overlay`에 `data-memo-theme`이 없으면 다크 메모지가 통째로 죽는다.
- 다크 메모지의 배경은 2레이어다 — 첫 레이어만 읽으면 오독한다.
- `--memo-canvas`는 메모지 **아랫변** 색이다. 윗변에 쓰지 마라.
  "새 색 금지"를 지키려다 **있는 변수 중 틀린 것**을 고르지 마라.

## 편집 구조

- `close(); show()`로 `<dialog>` 모달만 풀지 마라 — 먼슬리에서 시도하고 폐기했다.
  `show()`의 focusing steps가 툴바 버튼을 잡고, `backdrop-filter`가 ⋮ 시트를 화면 밖으로 보낸다.
- 하드코딩 `\n` + `white-space: pre-line`은 도움말에 두 군데 있다.
- 본문 확장(`.expand-btn`)은 모바일에서 `display:none`이라 도달 경로가 없다 — 데스크톱 전용이다.
- 되돌린 구조 시도 목록은 `frozen-features.md`가 센다.

## 저장 / 자동저장

- 자동저장이 무서워 테스트를 건너뛰지 마라 — **새 항목**을 쓰면 된다.
  신규는 id가 없어 자동저장이 early-return이다.
- UI를 닫는 `setState`를 서버 왕복 **뒤에** 두지 마라. "느리다/렉"이면 여기부터 봐라.
- 저장 payload는 `buildMemoInput()` 하나를 거친다 — 새 경로를 만들지 말고 그것을 써라.
