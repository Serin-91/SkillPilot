# PHASE 1 실기기 체크리스트 (③~⑦ 묶음 smoke test)

> 로컬(1280×800 / 375×684 × light/dark)은 **전부 통과**했다. 여기 있는 항목은
> **로컬에서 원리적으로 증명이 안 되는 것만** 남긴 것이다 — iOS 키보드, 주소창,
> 하드웨어 뒤로가기, PWA standalone.
>
> 세 환경에서 각각 돌린다: **① iOS Safari(또는 Chrome) ② Android Chrome ③ 설치형 PWA(standalone)**
> 각 항목 끝의 `정상:` 이 판정 기준이다. 그대로 `OK` / `NG + 본 것` 으로 답해주면 된다.

검사 대상 화면 5개:

| 기호 | 화면 | 어디서 여나 |
|---|---|---|
| ③ | 자료 선택 팝업 | ⑦ 안에서 **프로젝트 선택** 버튼 |
| ④ | My Page(설정) | 헤더 우측 계정 버튼 |
| ⑤ | 프로젝트 목록 | 대시보드 **프로젝트 아이디어** 패널 |
| ⑥ | Today's Focus | 대시보드 **⚡ Today's Focus** 카드 |
| ⑦ | Idea Build | 대시보드 **💡 Idea Build** 카드 |

⚠️ **누르면 안 되는 것**: ⑦의 `Idea ON` / `재생성`, ⑥의 `Focus ON` — **AI를 돌려서 DB에 쓴다.**
⚠️ ⑤에서 **프로젝트 행을 탭하면 모바일에서는 곧바로 편집·자동저장**이다. 목록만 보고 나와라.

---

## A. 열고 닫기 (5화면 × 3환경)

**A-1. 다섯 화면이 다 열리나**
③④⑤⑥⑦를 차례로 열어본다.
`정상:` 다섯 다 열린다. 화면이 비거나 흰 판이 뜨거나 글자만 나오는 것이 **없다**.

**A-2. ✕로 닫으면 원래 자리로 돌아오나**
대시보드를 **중간까지 스크롤한 상태**에서 각 화면을 열고 ✕로 닫는다.
`정상:` 닫은 뒤 **열기 전에 보던 그 위치**가 그대로다. 맨 위로 튀지 않는다.

**A-3. 닫은 뒤 대시보드가 다시 스크롤되나** ← 제일 중요하다
각 화면을 ✕로 닫은 직후 손가락으로 대시보드를 위아래로 굴린다.
`정상:` 정상적으로 굴러간다. **한 번이라도 "굴러가지 않는다"가 나오면 그 화면 이름을 적어줘.**

**A-4. 재진입**
같은 화면을 **연속으로 3번** 열고 닫는다.
`정상:` 3번 다 처음과 똑같이 보인다. 두 번째부터 위가 잘리거나 내용이 겹치지 않는다.

**A-5. ③은 ⑦ 안으로 돌아오나**
⑦을 열고 → **프로젝트 선택**(③)을 열고 → ③만 ✕로 닫는다.
`정상:` ③만 사라지고 **⑦은 그대로 열려 있다.** ⑦까지 같이 닫히면 NG.

## B. iOS / Android 고유 경로 (로컬에 없는 것)

**B-1. 하드웨어/제스처 뒤로가기** (Android 뒤로가기 버튼, iOS 화면 왼쪽 끝 스와이프)
각 화면을 **✕가 아니라 뒤로가기로** 닫는다.
`정상:` 화면이 닫히고 **대시보드가 다시 스크롤된다.**
🔴 **여기서 "스크롤이 죽는다"가 나오면 그것은 알려진 기존 버그다**(PHASE 1 회귀가 아니다).
그래도 **어느 화면에서 났는지 적어줘** — 기존 버그 재현 여부 확인에 쓴다.

**B-2. 키보드 — ④ My Page 보안설정**
④를 열고 **보안설정 탭**의 비밀번호 칸을 탭해서 키보드를 올린다.
`정상:` ① 지금 입력하는 칸이 **키보드에 가리지 않는다** ② 아래로 굴려서 **마지막 카드까지 닿는다**
③ 키보드를 내리면 원래 여백으로 돌아온다.

**B-3. 키보드 — ③ 검색칸**
⑦ → ③을 열고 상단 **검색칸**을 탭한다.
`정상:` 목록이 키보드 위에 남아 있고 **스크롤된다.** 입력할 때 화면이 손가락 따라 움직이지 않는다.

**B-4. 주소창 접힘** (iOS Safari / Android Chrome, PWA는 해당 없음)
대시보드를 굴려 주소창이 접힌 상태에서 각 화면을 열고 닫는다.
`정상:` 화면 위·아래가 **잘리지 않는다.** 닫은 뒤 빈 띠가 남지 않는다.

**B-5. 화면 회전** (가로 → 세로)
④와 ⑦을 열어둔 채로 기기를 가로로 돌리고 다시 세로로.
`정상:` 레이아웃이 다시 맞춰지고 내용이 잘리지 않는다.

## C. PWA standalone 전용 (홈 화면에 설치한 앱으로)

**C-1. 화면 끝 잘림**
③④⑤⑥⑦를 열어본다.
`정상:` **맨 위 ‹ / ✕ 버튼**과 **맨 아래 내용·버튼**이 화면 밖으로 안 나간다.
아이폰은 아래 홈 바(가로 막대)에 버튼이 겹치지 않아야 한다.

**C-2. 닫은 뒤 스크롤** — A-3과 같은 것을 standalone에서 한 번 더.
`정상:` 대시보드가 다시 굴러간다.

**C-3. 키보드** — B-2를 standalone에서 한 번 더(설치형은 주소창이 없어서 값이 다르다).
`정상:` 입력칸이 키보드에 안 가린다.

---

## D. 라이트 / 다크 둘 다

**D-1.** 위 A 묶음을 **라이트에서 한 번, 다크에서 한 번.**
`정상:` 다섯 화면 모두 배경·글자·테두리가 자기 테마 색이다.
흰 판이 번쩍하거나, 다크에서 밝은 카드가 뜨거나, 카드 둘레에 **밝은 선**이 보이면 NG.

⚠️ 브라우저에 **Dark Reader** 확장이 켜져 있으면 색이 틀려 보인다 — 껐는지 먼저 확인.

## 답 주는 형식 (이대로 주면 된다)

```
iOS:      A-1 OK / A-2 OK / A-3 NG(④에서 스크롤 죽음) / A-4 OK / A-5 OK
          B-1 ... / B-2 ... / B-3 ... / B-4 ... / B-5 ...
Android:  A-1 ... (같은 식)
PWA:      C-1 ... / C-2 ... / C-3 ...
Light/Dark: D-1 ...
```

NG가 있으면 **그 화면 이름 + 무엇이 보였는지 한 줄**이면 충분하다. 스크린샷이 있으면 제일 좋다.
